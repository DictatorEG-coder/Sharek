# شارك (Sharek)

تطبيق Android لمشاركة الملفات مباشرة بين هاتفين، دون الاعتماد على خادم خارجي أو اتصال إنترنت.

## الحالة الحالية
- [x] تأسيس مشروع Kotlin + Jetpack Compose
- [x] واجهة عربية RTL أولية
- [x] شاشة رئيسية للإرسال والاستلام
- [x] ألوان قرمزية وزرقاء كهربائية
- [x] إعداد GitHub Actions لبناء APK تجريبي
- [x] اختيار الملفات عبر Storage Access Framework (ملف أو عدة ملفات)
- [x] اكتشاف الهاتف تلقائيًا (NSD/mDNS) + إدخال عنوان IP يدويًا كبديل
- [x] نقل الملفات عبر TCP بالـ Streaming (لا تُحمَّل في الذاكرة) مع التقدم والسرعة
- [x] التحقق بـ SHA-256 وحفظ في Download/Sharek دون الكتابة فوق ملفات موجودة
- [x] رمز QR للاتصال (يظهر على المستقبل ويُمسح من المرسل)
- [ ] Wi-Fi Direct (غير منفّذ عمدًا: غير مستقر بين الأجهزة، والشبكة المحلية/Hotspot تغطي الحاجة)

## البناء
من Android Studio أو عبر GitHub Actions:
`gradle assembleDebug`

## الحزمة
`com.sharek.app`

## طريقة الاختبار بين هاتفين
1. ثبّت الـ APK على الهاتفين، وصِلهما بالشبكة نفسها (Wi-Fi واحد، أو شغّل Hotspot على أحدهما واتصل به من الآخر).
2. على الهاتف الثاني: «استلام» — يظهر «جاهز للاستلام» مع عنوان IP.
3. على الهاتف الأول: «إرسال» ← «اختيار الملفات» ← اضغط اسم الهاتف الثاني (أو «مسح رمز QR» من شاشة الاستلام، أو أدخل IP يدويًا ← «اتصال وإرسال»).
4. على الهاتف الثاني اضغط «قبول».
5. بعد اكتمال النقل والتحقق، تجد الملفات في `Download/Sharek` ويمكن فتحها من التطبيق.

## ملاحظات
- الحد الأدنى Android 10 (API 29) لأن الحفظ يتم عبر MediaStore دون صلاحيات تخزين.
- إن وُجد ملف بالاسم نفسه يُحفظ الملف الجديد باسم مختلف مثل `name (1).ext` ولا يُكتب فوق القديم.
- يُفضَّل إبقاء الشاشة مفتوحة أثناء النقل.

## الإصدار 0.3 — واجهة شاملة
- الشاشة الرئيسية: إرسال، استلام، التطبيقات، الصور والفيديوهات، الملفات، جهات الاتصال، سجل النقل، الإعدادات.
- اختيار المحتوى داخل التطبيق: التطبيقات (APK) بأيقوناتها، الصور والفيديوهات في شبكة مع الحجم والمدة، الملفات حسب النوع عبر منتقي النظام، جهات الاتصال (تُرسل كملف vCard واحد).
- الأذونات تُطلب عند فتح القسم فقط (صور/فيديو، جهات الاتصال)، مع بديل عبر منتقي النظام إن رُفض الإذن.
- شاشة النقل: نسبة التقدم، السرعة، المنقول والمتبقي، الوقت المتبقي التقريبي، وإلغاء النقل.
- سجل النقل: المرسل والمستلم، اسم الجهاز الآخر، التاريخ، الحالة، فتح الملف، وإعادة الإرسال.
- أزرار قناة تيليجرام ومشاركة التطبيق (Sharesheet)، وأيقونة Adaptive Icon.
- بروتوكول النقل لم يتغيّر (متوافق مع الإصدارات 0.2).
- غير منفّذ عمدًا: الإيقاف المؤقت/الاستئناف، لأنه يتطلب تغيير مهلات البروتوكول أو صيغته.
